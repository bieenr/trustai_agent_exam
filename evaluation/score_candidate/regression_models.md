# Thí nghiệm: ba mô hình hồi quy rating, chấm theo ngưỡng tuyệt đối và ngưỡng theo user

- Train: 7377 cặp `ratings_validation.csv` (đặc trưng tính từ train, 13 đặc trưng). Test: 7664 cặp, 610 user (cùng các cặp của `scripts.eval_score_models_full`).
- ridge: StandardScaler + Ridge(α=1). gbm_reg: `HistGradientBoostingRegressor` (như `scripts.eval_relative_labels`). ordinal: hồi quy thứ bậc proportional-odds trên 10 mức rating, dự đoán = rating kỳ vọng. bias: user_mean + movie_bias. Mọi dự đoán cắt về [0.5, 5].
- Nhãn tương đối: **thích** ⇔ rating − user_mean ≥ +0.5, **không thích** ⇔ ≤ −0.5. Nhãn tuyệt đối: ≥ 4.0 / ≤ 2.5.
- Luật theo user: “lệch ±δ” so offset = dự đoán − user_mean với δ; “lệch ±kσ user” chia offset cho độ lệch chuẩn rating của user trong train; “chọn trên val”: ngưỡng offset thấp nhất cho precision (nhãn tương đối) pass ≥ 80%, fail ≥ 70% trên dự đoán out-of-fold (GroupKFold theo user).
